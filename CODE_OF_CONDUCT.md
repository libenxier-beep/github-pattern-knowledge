# Code of Conduct

## Our Standard

This project is for building useful agent-readable engineering knowledge. Contributions should keep the space practical, respectful, and evidence-oriented.

Expected behavior:

- Be respectful and direct.
- Assume good intent, but accept corrections quickly.
- Critique ideas, code, evidence, and tradeoffs rather than people.
- Keep discussions focused on making the project more reliable and useful.
- Respect privacy. Do not post secrets, private generated knowledge, or personal data.

Unacceptable behavior:

- Harassment, insults, threats, or personal attacks.
- Publishing private information without permission.
- Repeated off-topic disruption.
- Pushing unverified claims as accepted project knowledge.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when behavior makes the project unsafe or unproductive.

If you see a problem, open a GitHub issue with the smallest safe amount of context. For security-sensitive or private matters, follow `SECURITY.md`.
