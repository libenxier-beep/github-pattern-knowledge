# Changelog

All notable changes to this project are documented here.

This project follows a lightweight changelog format inspired by Keep a Changelog.

## 0.1.0 - 2026-06-12

### Added

- Local daily loop for discovering or seeding GitHub repositories.
- Commit-pinned ingestion for README, metadata, tree summaries, and selected files.
- Deterministic heuristic extractor.
- Optional LLM extraction and review from bounded evidence packs.
- Harness validation for accepted pattern notes.
- Markdown-first knowledge output with generated JSON indexes.
- Local Vite dashboard for cards, indexes, runs, rejected drafts, and archive summaries.
- Seed pool and learned-repo registry.
